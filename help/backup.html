백업 · 복원

① 백업 : 지금 상태를 앱 안에 저장하고, 이어서 파일로도 저장합니다.

② 복원 : 저장해 둔 때로 되돌아갑니다.

③ 파일 저장 창을 닫으면 이렇게 앱 안에만 백업됩니다.

백업을 누르면 뜨는 파일 저장 창

① 저장을 누르면 휴대폰에 백업 파일이 생깁니다. 휴대폰을 바꿀 때 이 파일로 옮깁니다.

자세한 설명

  • 백업 단추 : 지금 상태를 휴대폰 앱 안에 한 번 저장하고, 이어서 같은 내용을 파일로도 저장합니다.
  • 들어가는 것 : 시간표, 달력, 근무 기록, 메모, 저장된 노선. 파일에는 알림 설정까지 모두 들어갑니다.
  • 복원 단추 : 목록에서 되돌아갈 때를 누르고 한 번 더 확인하면 그때 상태로 돌아갑니다.
  • 앱을 지웠다 다시 깔거나 휴대폰을 바꿨을 때는 복원 → '파일에서 복원'을 눌러 저장해 둔 파일을 고르면 그대로 옮겨집니다.
  • 저절로 하는 백업 : 시간표 한꺼번에 넣기를 할 때, 저장된 노선을 기본 노선으로 바꿀 때, 복원할 때는 바뀌기 바로 전 상태를 앱 안에 저절로 저장합니다.
  • 앱 안에는 최근 10개까지 남고, 넘치면 가장 오래된 것부터 지워집니다.
  • 내용이 똑같은 백업이 여러 개 있으면 복원 목록에는 가장 새것 하나만 보입니다.
  • 앱 안 백업은 파일 관리 앱에서 보이지 않고 앱을 지우면 함께 지워집니다. 휴대폰을 바꿀 때는 파일 백업이 있어야 합니다.
